## Release notes

### Welcome to Our Date Planner

A small interactive website made for choosing our perfect date.

### Included

- Personalized welcome page for Faye
- Date themes with automatic Combo detection
- Dress-up choices
- Multiple activity choices
- Extras including flowers, chocolates, Popchips, and smoked salmon
- Date and time selection
- Playful kiss and cuddle bill
- Email bill submission
- Responsive phone, tablet, and desktop layout
- Minimalist tulip background artwork

### How to use

Download the project, open `index.html`, and click **Schedule date**. No VS Code or installation is needed.

### Notes

An internet connection is needed to send the email. If the email is not visible immediately, check the spam or junk folder.
