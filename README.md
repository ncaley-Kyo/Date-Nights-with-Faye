# Our Date Planner

Hi Faye. This is our little date planner.

## How To Use It

1. Open `index.html`.
2. Click **Schedule date**.
4. Choose the type of date, what to wear, activities, extras, date, and time.
5. Click **See the bill**.
6. On the final page, click **Email bill**.

You do not need VS Code or any special app. A normal web browser is enough. An internet connection is needed for the email button.

## If It Does Not Open

If double-clicking `index.html` does not open it properly, right-click the file and choose **Open with**, then select Chrome, Edge, or another browser.

## Sending The Email

The email is already connected to Niall's email address. Make sure the device is connected to the internet, then click **Email bill** on the final page.

If the email does not appear immediately, check the spam or junk folder.

## Sharing The Site

The easiest way to share it is with the website link. Open the link in any browser on a phone, tablet, or computer. No download or VS Code installation is needed.

If you are given the files instead of a link, open `index.html` from the folder.

Have fun choosing our date.
