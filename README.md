# Our Date Planner

Hi Faye. This is our little date planner.

## Quickest Way To Use It

You do not need VS Code, Node.js, or any other software.

1. On GitHub, click the green **Code** button.
2. Choose **Download ZIP**.
3. Open the downloaded ZIP file.
4. Open the folder inside it.
5. Double-click `index.html`.
6. Click **Schedule date** and choose our date.

Use Chrome, Edge, Safari, or another normal web browser. An internet connection is needed when sending the email.

## Choose Our Date

1. Choose one or more date themes. Choosing more than one creates a Combo and costs extra kisses.
2. Choose what to wear.
3. Choose any activities.
4. Choose any extras: flowers, chocolates, Popchips, or smoked salmon.
5. Choose a date and time.
6. Review the love bill.
7. Click **Email bill**.

The email is sent to Niall. If it does not appear straight away, check the spam or junk folder.

## Easiest Way To Share A Link

If you want a link instead of a ZIP file, the repository owner can turn on GitHub Pages:

1. Open the repository on GitHub.
2. Click **Settings**.
3. In the left menu, click **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait a minute, then open the link GitHub provides.

Send that link to anyone. They only need a browser and an internet connection.
